# Image2PDF

The easiest way to convert images to PDF - 100% private, fast, and free!

## Features

- 🔒 **100% Private** - All processing happens in your browser. Files never leave your device.
- ⚡ **Fast & Easy** - Convert images to PDF in seconds with a simple drag & drop interface.
- 💰 **Free Forever** - No watermarks, no limits, no registration required.
- 📱 **Responsive Design** - Works on desktop, tablet, and mobile devices.
- 🎨 **Customizable Output** - Choose page size, orientation, margins, and image scaling.

## Supported Formats

- PNG
- JPEG
- WebP

## Installation

```bash
git clone https://github.com/KidiXDev/image2pdf.git
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
